Architectural Excellence

Designed to Outperform Big Tech.

Every layer of Orion is optimized for memory efficiency, cryptographic privacy, and zero telemetry.

🛡️

Tor Multi-Stage Security Shield

Toggle between Standard, Safer, and Safest execution profiles. Safest mode disables JavaScript globally to prevent browser fingerprinting, while the one-tap "New Identity" instantly purges all session cookies, cache, and history from RAM.

✓ Standard: Adblock & DoH active • ⚠ Safer: Block HTTP JS • ⛔ Safest: Zero JS execution
⚡

Sub-1ms Ad Interception

Unlike slow JavaScript extensions, Orion intercepts requests in native memory before network dispatch, dropping DoubleClick, Outbrain, and trackers instantaneously.

204 No Content • 0ms overhead
🎬

Turbo 4x Stream Extractor

Captures dynamic <video> blob URLs, MP4 containers, and HLS playlists. Splits single files into 4 parallel HTTP byte-range slices to bypass ISP throttling.

🔐

Biometric Secret Vault with AES-256 Storage

Private tabs are locked behind Android BiometricPrompt (Fingerprint) and Apple Face ID. Downloaded private media is encrypted directly with AES-256 (GCM) using hardware Keystore keys, completely hidden from public galleries and file managers.

Cipher: AES/GCM/NoPadding • Hardware Keystore Secured
🎵

Screen-Off Audio Playback

Runs playback through an Android ForegroundService and iOS audio background mode. Music, YouTube audio, and podcasts continue playing with screen locked.

🚀

Cloudflare 1.1.1.1 DoH

Pre-resolves hostnames over DNS-over-HTTPS, preventing ISP DNS hijacking, eavesdropping, and carrier-level domain blocking.

🌙

OLED True-Black Shader

Universal dynamic CSS shader forcing genuine #000000 deep blacks across all websites to maximize battery life on AMOLED screens.
